## Reproducibility note

`evals/results/actual/*.json` are pre-generated by performing this Skill's Step 6 analysis once per case, then running `scripts/score.py` and `scripts/validate_report.py` on the result - the same deterministic scripts a real run uses. Re-running this harness against the same `actual/*.json` files always reproduces the same metrics, since every check above is a pure function of already-recorded data. Re-running the *analysis step* itself is not expected to reproduce byte-identical prose (it is a judgment call, not a deterministic script) - reproducibility here means these five metrics stay stable across such re-runs, not that the wording stays identical.
